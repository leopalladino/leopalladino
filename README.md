# Leonardo Victor Palladino

Data scientist working on credit risk, collections and LLM systems at AMPF, a mutual aid association in Argentina. I build the models that score and collect member debt, and evaluate the LLM chatbots that talk to our members on WhatsApp.

### Selected work

Most of it is private, built for AMPF and for clients.

- **Credit risk (AMPF):** ported the production credit score from PL/SQL to Python at 99.3% agreement, then built an interpretable scorecard that beats it out-of-time (AUC 0.73 vs 0.60).
- **Collections analytics (AMPF):** daily KPI site for senior management, fed by a nightly pipeline on the Oracle core. Rebuilding the KPIs at member grain cut the gap with official figures from 7% to 0.5%.
- **LLM evaluation (AMPF):** validated an LLM judge against a labeled held-out set (κ 0.86) before using it in 8 controlled experiments, and fine-tuned a 300M encoder that beats the GPT-4o-mini intent router (87.7% vs 83.0%) at 9x lower latency.
- **SetterAI:** agentic CRM for Instagram DMs, where each sales chat is a state machine of LLM-gated steps with an LLM-as-judge veto.
- **[ammegtech.com](https://ammegtech.com):** generative AI SaaS that turns garment photos into studio-quality catalog shots.
