# Leonardo Victor Palladino

Data Scientist at AMPF, a mutual aid association with more than 80,000 members in Argentina. I work on machine learning models for credit risk and collections, and on the inbound and outbound LLM chatbots that talk to our members on WhatsApp.

### Selected work

Most of it is private, built for AMPF and for clients.

- **Credit risk (AMPF):** replaced a rule-based credit score with Gradient Boosting, going from an AUC of 0.68 to 0.78, and validated it on out-of-time cohorts at the same approval rate.
- **RAG and evals (AMPF):** split the knowledge base by intent with an intent router, cutting context tokens 40% without losing recall@5, and calibrated an LLM judge against human labels before using it as a release gate.
- **SetterAI:** agentic CRM for Instagram DMs, where each sales chat is a state machine of LLM-gated steps with an LLM-as-judge veto.
- **[ammegtech.com](https://ammegtech.com):** generative AI SaaS that turns garment photos into studio-quality catalog shots.

Python · SQL · Scikit-learn · PostgreSQL · pgvector · OpenAI API · Langfuse · FastAPI
